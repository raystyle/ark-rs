## 裁定与先例核对

- **A13 四件断言实文**（ohmycloud `.tools\wsl-verify.sh`）：npm registry 读出 npmmirror；`~/.cargo/config.toml` rsproxy 计数 ≥3；`~/.config/uv/uv.toml` tsinghua 计数 ≥1；`~/.bashrc` 内 RUSTUP_DIST_SERVER / RUSTUP_UPDATE_ROOT / FNM_NODE_DIST_MIRROR 合计 ≥3 行。四族正对 fnm / uv / rust / node 面。
- **本仓先例**：rustup.rs 已有 rsproxy 全量原生落法（Windows）；heal_bunfig / heal_goproxy 为镜像整文件写回语义；manifest L1 `env_set` 的 POSIX 通道即 profile env 块（shell rc）；`set_user_env_var` 双通道正是「win 用户环境变量、POSIX shell rc」裁定口径的现成落法。
- **遗产全集**（set-mirror.ps1）：uv / pip 清华 TUNA、python 安装 NJU（UV_PYTHON_INSTALL_MIRROR）、fnm 走 npmmirror node dist、npm / bun 走 registry.npmmirror.com、rust 走 rsproxy 全量；另撤旧通道四变量（UV_INDEX_URL / UV_DEFAULT_INDEX / PIP_INDEX_URL / PIP_TRUSTED_HOST，env 值会盖过文件配置）。

## 落码面

1. **manifest mirror 节（R016 L1 扩展，不升 schema）**：七键（`env` / `env_unset` / `npm_registry` / `bunfig_registry` / `uv_index` / `pip_index` / `cargo_config`），值数据面声明、落点与合并语义引擎按类型实现一次。npmrc **行级 upsert** 保认证行（npmrc 常载凭据，整文件重写会毁数据）；bunfig / uv / pip / cargo 内容比对整写；bunfig URL 比对去尾斜杠（npmmirror 两写法等价不来回重写）。
2. **接线**：`apply_manifest_primitives` 在 env_set 后、post_install 前调 `apply_mirror`（镜像 env 进程内即设，fnm install 立即经 npmmirror 拉 node）；幂等分支与 uv-git / npm-tgz 早退通道共用同点（存量端升级即得，共识③同款）；失败硬错（L1 语义）；整面受 `ARK_TEST_NO_PATH_REG` 闸门（用户环境写入面第五面）。
3. **platform**：`remove_user_env_var`（win 注册表删值加进程同步加广播；POSIX env 块摘行、体空整块收口），`remove_env_export` 纯函数入测。
4. **rust POSIX 接管**：`rustup.rs` 拆 `install_windows` / `install_posix`；POSIX 系统标准位 `~/.rustup` 与 `~/.cargo`（R010，不重定位、不设两 HOME 变量）、rsproxy rustup-init 引导（evergreen 边车锚、chmod 755、host 三元组自检）、持久 RUSTUP_DIST_SERVER / RUSTUP_UPDATE_ROOT（POSIX 落 profile env 块即 `.bashrc`）、cargo config rsproxy 全量（三处 rsproxy 关键标志对齐 A13 ≥3 判据，单测锁形态）、PATH `~/.cargo/bin`。Windows 分支逐字未动（零回归面）。
5. **配套**：verify 增 POSIX dev-rust 维度（`~/.cargo/bin/rustc` 加 `~/.rustup/toolchains`）、heal dev-rust 键开 POSIX；heal_bunfig 委托 manifest `ensure_bunfig`（bunfig 写语义单一权威，防双份漂移）；catalog_lint 增 mirror 面（空节应省略）；fixtures 增 fnm / uv / bun 三节基准形态（omc 数据面抄写基准）；tests/install.rs 增幂等分支 mirror 接线与闸门用例。
6. **文档**：R016 增 mirror 节规范与 D42 实现状态；README 镜像源节与 install 链；SKILL install 行；CHANGELOG；INDEX；PLAN / PRD（D42）/ GOAL / TODO 立项登记；版本 1.0.0 升 1.1.0（tag 待指示）。

## 验证

- 单测加集成全绿（Windows 本机 `cargo test` 加 `cargo clippy` 干净）；POSIX 面单测 cfg 下沉（M016 纪律），WSL 面留验收。
- **Windows 真机全链**（隔离 catalog 注入、真 HOME）：四键终态 `~/.npmrc` registry=npmmirror、`~/.bunfig.toml` npmmirror、`%APPDATA%\uv\uv.toml` TUNA、`%APPDATA%\pip\pip.ini` TUNA；镜像 env FNM_NODE_DIST_MIRROR 注册表读回；`env_unset` 预置旧变量 UV_INDEX_URL 实撤；二连幂等全「已是目标态」；`npm config get registry` 读出 `https://registry.npmmirror.com`。
- **uv Windows 发现位实证**：uv 0.12.6 只认 `%APPDATA%\uv\uv.toml`（写探针 URL 后 `uv pip install --dry-run` 实际去拉探针地址），不读 `~/.config/uv`；故 uv / pip 落 `dirs::config_dir()` 平台位（POSIX 即裁定字面位 `~/.config/uv/`）。本机已是目标态（开发机四件配置顺带落齐，值同裁定）。
- **坑记 M029**：Windows 用户目录解析走 known folder API 不吃 env 覆盖，隔离 HOME 端到端两轮失真后改为注入路径单测加真机直跑收口。

| # | 级 | 结论 | 修复 |
| --- | --- | --- | --- |
| R1 | 中 | POSIX `env_unset` 不撤托管块外的旧变量（遗产 set-mirror / 手写形态）却报「已撤」；`get_user_env_var` 注释与实现口径不一 | `remove_env_export` 改**全文件撤变量不分写入者**（托管块内摘行加体空收口，块外同名行同摘）；`remove_user_env_var` 按写后文本真变化报告；注释对齐（get 扫全 profile 如实写明） |
