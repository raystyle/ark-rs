## 落码面

1. **manifest mirror 节（R016 L1 扩展，不升 schema）**：七键（`env` / `env_unset` / `npm_registry` / `bunfig_registry` / `uv_index` / `pip_index` / `cargo_config`），值数据面声明、落点与合并语义引擎按类型实现一次。npmrc **行级 upsert** 保认证行（npmrc 常载凭据，整文件重写会毁数据）；bunfig / uv / pip / cargo 内容比对整写；bunfig URL 比对去尾斜杠（npmmirror 两写法等价不来回重写）。
2. **接线**：`apply_manifest_primitives` 在 env_set 后、post_install 前调 `apply_mirror`（镜像 env 进程内即设，fnm install 立即经 npmmirror 拉 node）；幂等分支与 uv-git / npm-tgz 早退通道共用同点（存量端升级即得，共识③同款）；失败硬错（L1 语义）；整面受 `ARK_TEST_NO_PATH_REG` 闸门（用户环境写入面第五面）。
3. **platform**：`remove_user_env_var`（win 注册表删值加进程同步加广播；POSIX env 块摘行、体空整块收口），`remove_env_export` 纯函数入测。
4. **rust POSIX 接管**：`rustup.rs` 拆 `install_windows` / `install_posix`；POSIX 系统标准位 `~/.rustup` 与 `~/.cargo`（R010，不重定位、不设两 HOME 变量）、rsproxy rustup-init 引导（evergreen 边车锚、chmod 755、host 三元组自检）、持久 RUSTUP_DIST_SERVER / RUSTUP_UPDATE_ROOT（POSIX 落 profile env 块即 `.bashrc`）、cargo config rsproxy 全量（三处 rsproxy 关键标志对齐 A13 ≥3 判据，单测锁形态）、PATH `~/.cargo/bin`。Windows 分支逐字未动（零回归面）。
5. **配套**：verify 增 POSIX dev-rust 维度（`~/.cargo/bin/rustc` 加 `~/.rustup/toolchains`）、heal dev-rust 键开 POSIX；heal_bunfig 委托 manifest `ensure_bunfig`（bunfig 写语义单一权威，防双份漂移）；catalog_lint 增 mirror 面（空节应省略）；fixtures 增 fnm / uv / bun 三节基准形态（omc 数据面抄写基准）；tests/install.rs 增幂等分支 mirror 接线与闸门用例。
6. **文档**：R016 增 mirror 节规范与 D42 实现状态；README 镜像源节与 install 链；SKILL install 行；CHANGELOG；INDEX；PLAN / PRD（D42）/ GOAL / TODO 立项登记；版本 1.0.0 升 1.1.0（tag 待指示）。
